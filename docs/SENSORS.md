# 传感器、阈值与波动算法

## 1. 数据来源

传感器由 LibreHardwareMonitorLib 0.9.6 从 CPU、GPU、主板、内存、存储和控制器读取。程序只显示设备实际提供的数据。

## 2. 为什么不同传感器都重要

| 类型 | 示例 | 重要性 | 高低说明 |
| --- | --- | --- | --- |
| CPU 温度 | CPU Package、Core Max | 核心指标；影响稳定性、降频和寿命 | 高负载 80°C 以上需要关注；接近 100°C 危险 |
| GPU 温度 | GPU Core | 游戏性能与稳定性的核心指标 | 游戏约 72–85°C 常见；95°C 以上过高 |
| GPU 热点 | Hot Spot、Junction | 芯片内部最热点；可能先触发限制 | 常高于核心温度；110°C 以上危险 |
| 显存温度 | Memory Junction | 显存密集型游戏和计算负载 | 90°C 以上偏热，100°C 以上过高 |
| 风扇 RPM | Fan #1、CPU Fan | 反映主动散热能力 | 高温时仍为 0 或极低需要检查 |
| CPU/GPU 负载 | Total、Core Load | 判断温度是否与任务强度匹配 | 高负载高温度通常正常，空闲高温异常 |
| 功耗 | Package Power、GPU Power | 直接影响发热和性能释放 | 绝对值因机型而异，适合同机前后比较 |
| 频率 | Core Clock、GPU Clock | 反映活跃程度和降频 | 高负载时频率明显下降可能与温度/功耗限制有关 |
| 电压和电流 | Core Voltage、Current | 检查供电状态 | 没有通用绝对阈值，应参考具体硬件 |
| 主板/系统温度 | System、VRM | 反映整机内部热环境 | 持续 >70°C 应关注风道 |
| 存储温度 | NVMe Temperature | 高温会导致降速和寿命风险 | >70°C 偏热，>80°C 过高 |
| 内存温度 | DIMM Temperature | 高频内存稳定性 | >72°C 偏热，>85°C 过高 |
| 容量/吞吐量 | Used Space、Throughput | 补充运行状态 | 结合任务和趋势判断 |

## 3. 温度状态算法

### CPU

无负载参考：

- 低于约 60°C：合适。
- 60–75°C：偏热。
- 75°C 以上：偏高。
- 90°C 以上：过高。

负载超过约 20% 时使用工作负载阈值：

- 低于约 80°C：合适。
- 80–89°C：偏热。
- 90–99°C：过高。
- 100°C 及以上：危险。

### GPU

无负载参考：

- 低于约 60°C：合适。
- 60–72°C：偏热。
- 72–85°C：偏高。
- 85°C 以上：过高。

游戏或其他 GPU 负载超过约 20% 时：

- 低于约 86°C：合适。
- 86–94°C：偏热。
- 95°C 及以上：过高。

### GPU 热点

- 低于约 90°C：合适。
- 90–99°C：偏热。
- 100–109°C：过高。
- 110°C 及以上：危险。

### 整机判断

程序选择 CPU、GPU 和 GPU 热点中级别最高的一项，避免一个平均温度正常而另一个热点已经过热。

## 4. 波动算法

每个传感器维护最近最多 60 个一秒采样值。

标准差：

```text
σ = sqrt(Σ(x - mean)² / n)
```

峰谷差：

```text
range = max(recent) - min(recent)
```

温度波动级别：

| 标准差 | 级别 | 常见解释 |
| --- | --- | --- |
| <0.8°C | 平稳 | 温度稳定 |
| 0.8–2.0°C | 轻微波动 | 小型任务或风扇调速 |
| 2.0–3.5°C | 波动较大 | 负载、功耗限制或风扇频繁变化 |
| >3.5°C | 波动明显 | 需要检查负载、风扇策略和降频 |

波动本身不等于故障。程序会把温度水平和波动结合：

- 温度高、波动小：更像持续散热不足。
- 温度合适、波动大：更像任务变化或风扇/功耗策略变化。
- 温度高、波动大：优先降低负载并检查散热与风扇。

## 5. 清灰前后统计

每个测试阶段的全部传感器都会保存：

- 最小值
- 平均值
- 最大值
- 标准差
- 样本数

清灰对比中的波动行使用对应 CPU/GPU 主温度传感器的标准差，负变化表示清灰后更加平稳。

## 6. 限制

- 温度读数受传感器位置、EC/BIOS 实现和厂商隐藏策略影响。
- 不同笔记本之间的功耗和风扇 RPM 不可直接比较。
- 室温、桌面材质、垫高角度、电源模式和后台任务都可能影响结果。
- 阈值是面向常见笔记本的工程参考，不是厂商保修标准。
