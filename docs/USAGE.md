# 完整使用说明

## 1. 安装与启动

1. 下载 Release 中的 Windows x64 ZIP。
2. 将整个目录解压到可写位置。
3. 双击 `HardwareMonitorCenter.exe`。
4. 在 UAC 提示中允许管理员权限。
5. 首次运行如果出现 PawnIO 安装提示，请允许安装。
6. 安装完成后回到程序，等待传感器列表出现。

不要只复制 EXE。程序还需要同目录下的 DLL、配置文件、PawnIO 安装器和说明文档。

## 2. 总览页

总览页显示：

- CPU 温度、GPU 温度和 GPU 热点。
- CPU/GPU 使用率、功耗和频率。
- 风扇转速和当前可读取的最高温度。
- 最近 5 分钟双传感器趋势。
- 当前温度健康判断。

主曲线和副曲线下拉框可选择任意适合趋势显示的传感器。不同单位的曲线可以同时显示，但应结合图例理解。

## 3. 当前温度判断

程序优先使用 CPU、GPU 和 GPU 热点中风险最高的一项。CPU/GPU 温度阈值会根据当前负载切换：

- 无负载时使用较低的静置阈值。
- 游戏或其他高负载时允许更高的正常工作温度。
- 温度波动明显时，标题会额外标记“波动明显”。

状态说明：

| 状态 | 含义 | 建议 |
| --- | --- | --- |
| 合适 | 温度与波动在常见笔记本范围 | 保持通风，继续观察 |
| 偏热 | 温度高于常见舒适范围 | 检查风扇、进风口、电源模式和后台负载 |
| 过高 | 可能发生降频或稳定性问题 | 降低负载，检查散热器、风扇和硅脂 |
| 危险 | 接近设备高温保护区间 | 立即停止高负载并排查硬件散热 |

温度范围是辅助判断，不代表厂商的精确温度墙。

## 4. 全部传感器页

### 搜索

输入传感器名称、设备名或分组关键词即可实时筛选。

### 判断分类

判断列表会根据当前传感器动态生成，例如：

- 合适
- 偏热
- 过高
- 危险
- 空闲
- 有负载
- 高速
- 需参考设备

选择某个判断，只显示符合该判断的传感器。

### 类型和设备分类

类型包括温度、风扇、负载、功耗、频率、电压、电流和其他。

设备包括 CPU、GPU、主板、存储、内存、散热器等。

### 排序

支持：

- 默认设备分类
- 传感器名称 A–Z
- 当前值高到低
- 当前值低到高
- 温度高到低
- 温度低到高
- 温度波动高到低
- 温度波动低到高

### 详情

点击列表任意一行，可查看：

- 传感器介绍。
- 对健康和性能判断的重要性。
- 数值偏高或偏低的含义。
- 当前负载下的判断。
- 最近约 60 秒标准差和峰谷差。
- 风扇、负载、降频或散热方面的建议。

## 5. 无负载记录

目的：获得清灰前后在低负载、稳定环境下的基础温度。

步骤：

1. 关闭游戏、渲染、压缩、下载和其他大型任务。
2. 等待系统进入稳定状态。
3. 选择清灰阶段。
4. 负载类型选择“无负载”。
5. 点击“开始无负载记录”。
6. 静置 5 分钟。
7. 记录自动保存。

清灰前、清灰后应使用相同电源模式、摆放位置和相近室温。

## 6. 游戏负载记录

目的：比较真实游戏场景中的长期温度和功耗。

步骤：

1. 选择清灰阶段。
2. 负载类型选择“游戏”。
3. 填写游戏名称与固定场景。
4. 选择 5、10、15 或 20 分钟。
5. 点击“开始游戏负载记录”。
6. 立即切换到游戏。
7. 保持相同画质、分辨率、场景、帧率限制和大致操作。
8. 到时自动保存，或点击“结束并保存”。

清灰前后必须使用同一游戏和同一场景。不同地图、画质或角色位置会改变负载，导致对比无效。

## 7. 清灰前后对比

对比表分别显示：

- 无负载 CPU/GPU 平均与峰值温度。
- 无负载 CPU/GPU 温度波动。
- 游戏 CPU/GPU 平均与峰值温度。
- 游戏 GPU 负载。
- 最高风扇转速。
- CPU 功耗。
- 游戏 CPU/GPU 温度波动。

变化列使用“清灰后减去清灰前”：

- 负温度变化：清灰后更低。
- 负波动变化：清灰后更平稳。
- 正温度变化：清灰后更高。

## 8. 导出

### 当前传感器快照

导出当前所有传感器：

- 设备与分组。
- 类型和名称。
- 当前值。
- 运行期间最小、平均和最大值。
- 最近约 60 秒波动标准差。

### 完整对比报告

导出无负载和游戏记录，包括：

- 每次记录的时间和负载名称。
- 各阶段核心指标。
- 负载阶段全部传感器统计。
- 清灰前后对比表。

## 9. 数据目录

默认：

```text
<程序目录>\Reports\
```

无写权限时：

```text
%LOCALAPPDATA%\CleanTempCompare\Reports\
```

文件类型：

- `*_idle_latest.json`：最近一次无负载记录。
- `*_gaming_latest.json`：最近一次游戏记录。
- 带时间的 JSON：历史会话。
- raw CSV：每秒原始采样。
- 导出 CSV：快照或对比报告。

## 10. 常见问题

### 没有 CPU 温度

- 确认允许管理员权限。
- 首次启动安装 PawnIO。
- 关闭可能冲突的硬件监控程序后重启本程序。

### 没有风扇转速

部分笔记本不向操作系统公开风扇转速。这不会影响温度监测和对比。

### 游戏后温度没有立即下降

笔记本散热器和机身存在热惯性。关闭游戏后可能需要数分钟才能恢复到静置范围。

### 清灰后温度反而升高

- 检查散热器线缆和风扇接头。
- 检查散热器扣具和硅脂。
- 检查进风口是否被外壳或桌面堵塞。
- 确认测试室温、电源模式和游戏场景一致。
- 对比波动：温度高且持续稳定通常更像散热不足；温度正常但波动很大可能更像负载或风扇策略变化。
